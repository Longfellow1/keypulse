## Penpal v0.3.0-preview.1

本次预览版补齐首次使用流程、可选桌面 App 和多 AI 助手的授权隔离。

- **首次使用引导**：`penpal install onboard` 先说明数据边界，再逐个确认要开的来源（默认不开），显示所选来源需要的系统权限，最后分批导入历史。导入中断后重跑会从上次位置继续，不会重复入库。
- **可选菜单栏 App**：`penpal app install` 在 `~/Applications` 生成 Penpal.app（加 `--login` 开机自启），界面是重做后的 HUD：状态、AI 授权、隐私与删除。App 自己不需要任何系统权限，采集权限仍由后台服务持有；它能做的事，CLI 都能做。App 为 ad-hoc 签名，没有开发者证书。
- **Claude Code / Codex / Cursor 授权互不影响**：各自独立 token；撤销或轮换其中一个，另一个不受影响，被撤销的助手下一次调用立即被拒。
- **排除名单全程生效**：排除的域名不再绕过浏览器历史导入；开启网址观察器时，在排除网站的标签页里输入、复制的文字也只留应用与时间。
- **读不到的来源会说明原因**：文件缺失、没权限、数据库被锁、版本不支持都会写明原因，`penpal source list`、`penpal doctor` 和 AI 的查询结果里都能看到，不再静默当成"没有数据"。
- **键盘文字片段**：仍默认开启，只存过滤后的片段；首次运行会打印一次风险说明，`penpal doctor` 显示开关状态。在已授权的分类内可被 AI 搜索，一条命令可关：`penpal source disable keyboard_chunk`。
- **睡眠唤醒后自动恢复**：Mac 唤醒后重新检查权限、拉起停掉的采集器并重扫来源。
- **安装更稳**：修复 README 里 `curl | bash` 一行命令必定失败的问题；新增干净 macOS 上的安装检查。

**升级须知**

- 已装过预览版的用户：请重新运行一次 `install.sh`，或执行 `penpal install init`。旧版本的后台服务指向带版本号的 Homebrew 目录，`brew upgrade` 后会失效、采集静默停止；重跑后改为指向稳定路径，以后升级不再受影响。
- 新装机在你运行 `penpal install onboard` 之前不会读取历史来源（Chrome / Safari 历史、终端命令历史等），实时采集不受影响。已有安装不受此限制。
- 网页地址采集由 `penpal install init` 生成的 config.toml 开启，需要浏览器自动化权限；删掉或改成 `browser_url = false` 即关闭。
- 仍在试验或未做：中文输入法上屏文字的采集；仅支持 macOS；AI 只能读，不能写回。
