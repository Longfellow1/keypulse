两方案共同约定

  • 状态栏 icon：本本 + 一支正在写字的笔（模板图标，自动适配深浅色）
  • 灯色：●绿 正常 · ●黄 LLM 异常 / 未配置 · ●红 采集异常 / 数据异常 · ●灰 已暂停
  • 状态文本（带框胶囊）：正常 / LLM 异常 / 采集异常 / 数据异常 / 待配置 / 已暂停
  • 异常一句话指引（精简版）：
    • LLM API key 未配置，请前往 ~/.keypulse/secrets.env 配置
    • LLM API key 失效或余额不足，请检查
    • LLM 调用超时，请检查网络
    • 输入监控权限不足，请前往系统设置 → 隐私 → 输入监控
  • 底部按钮：重启（二次确认 → 调 launchctl kickstart）+ 暂停
  • 宽度：280 → 365px（+30%），三条提示标题不回行
  • 字重：品牌/数字 600，正文 500，辅助 500，整体颜色加深
